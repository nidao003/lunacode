## LunaCode v0.1.13 更新说明

### 1. 上游同步

- 合并上游 T3 Code `0.1.13` 主干代码，保持桌面端、Web 与移动端功能与稳定性同步升级（含内置 `MesloLGS NF` 终端字体与小组件适配）。

### 2. Human-in-the-Loop 可视化工作流工作室（`LUNA-020`）

- **声明式 `*.flow.json`（`FlowSpec` v1）执行引擎**：与上游编程式 `.ts` / `.js` 工作流并存兼容，支持 DAG 并行扇出/扇入、有界 `isLoop` + `maxHops` 人工审批熔断、零 Token `precheck` 门槛、`<untrusted_event_data>` 隔离及同项目并发 `root` 写冲突校验。
- **内置 8 套精选工作流模板**：首次启动通过 `.lunacode-flow-presets.json` 自动预置 6 套 `manual` 案例（`bug-repro-fix`、`pr-dual-review`、`ci-doctor-autofix`、`docs-drift-sync`、`release-notes-prep`、`daily-repo-standup`），并提供 `issue-triage` 与 `feature-plan-ship` 按需导入。
- **全端工作流编排与对话内 MCP 工具**：新增 `workflows.start` RPC 与 `t3_flow_*` MCP 工具集（支持多版本流迭代）；Web / Desktop 提供交互式 DAG 画布工作室、案例一键导入与运行期实时流程图，Mobile 同步提供竖向阶段 DAG 编排、一键案例导入与协作视图。

### 3. 全端版本对齐与升级体验修复（`LUNA-017` / `LUNA-019`）

- **统一桌面与移动端版本号**：移动端默认版本号与桌面端统一对齐为 `0.1.13`（自动派生递增 `ios.buildNumber` / `android.versionCode` 为 `113`，并在 GitHub Release CI 中向 Android / iOS 任务透传 `T3CODE_MOBILE_VERSION`）。
- **升级保留自建后台地址配置**：修复无默认硬编码域名构建在应用升级重启时恢复已保存自建后台地址（`serverUrl`）与会话的逻辑，升级后完整保留自建服务连接状态。
- **多架构后端镜像同步**：配套发布 `nidao008/lunacode-connect:0.1.13` / `:latest`（`linux/amd64` + `linux/arm64`）。

### 4. 中英文档同步与能力聚焦（`LUNA-014`）

- 更新中英文项目说明（`README.md`、`README.zh-CN.md`、`docs/lunacode.md`、`docs/lunacode.zh-CN.md`）及后端部署指南（`services/lunacode-connect/README.md`、`README.zh-CN.md`），补充 `LUNA-020` 可视化工作流工作室介绍与 `0.1.13` 镜像示例。
- 收口冗余的多 Bot 常驻集群实验（`LUNA-021`），聚焦可控的原生委托（`delegate_task` / Worktree）与可审查的可视化工作流编排。
