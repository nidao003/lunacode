## LunaCode v0.1.12 更新说明

### 1. 上游同步

- 合并上游 T3 Code `0.1.12` 主干代码，保持桌面端、Web 与移动端功能与稳定性同步升级。

### 2. 公开代码零私人信息 + 自建后台运行时配置（`LUNA-017`）

- **移除内置私人域名默认配置**：公开源码与安装包中不再预埋任何私人域名、邮箱、主机名或证书信息；构建默认开启自建认证模式（`LUNACODE_SELF_HOSTED_AUTH=1`），用户在各端直接填写自己的 `lunacode-connect` 服务地址即可启用登录与公网中继。
- **全端后台服务地址运行时切换**：桌面端（登录/注册弹窗顶部、账号与配额弹窗底部、设置 → Labs → LunaCode 定制能力顶部）、Web 与移动端（设置 → 连接/账号）均支持直接保存、切换并持久化自建后台地址；切换服务器时自动清理原会话并同步刷新桌面端 Electron CORS `Origin` 放行域名。
- **自建一体化中继服务与多架构 Docker Hub 镜像**：新增零外部依赖 Docker 中继服务端（[`services/lunacode-connect/`](../../services/lunacode-connect/)），提供邮箱账号、OAuth2 PKCE/Device Code、Relay v1、内置 `"t3_relay"` 二进制 WS 多路复用隧道、Webhook 离线队列、APNs/FCM/Expo 推送、容器托管 WebSPA 与 `/admin` 超管后台，并发布官方多架构镜像 `nidao008/lunacode-connect:0.1.12` / `:latest`（`linux/amd64` + `linux/arm64`）及一键构建/部署脚本（`scripts/build-image.sh`、`scripts/deploy.sh`），同时配置 GitHub Actions 自动推送流水线。
- **自建跨域预检与自助账号管理**：在自建认证模式下禁用 `b3` / `traceparent` 追踪头透传；桌面、Web 与移动端均内置修改昵称、修改密码与注销其他设备会话功能。

### 3. 全端品牌与更新下载源统一（`LUNA-001` / `LUNA-019`）

- **全端品牌一致性**：统一桌面端、Web 与移动端 `LunaCode` / `Luna Connect` 品牌展示与图标体系，并修复移动设备列表中残留 `T3 Code` 版本标识的展示细节。
- **统一更新源**：桌面端 `electron-updater`、CLI/Server 自更新、安装脚本与移动端关于页新版本检测统一切换至 `nidao003/lunacode` GitHub Releases。

### 4. 中英双语文档与完整差异/部署指引（`LUNA-014`）

- 更新默认英文文档（`README.md`、`docs/lunacode.md`、`services/lunacode-connect/README.md`）并新增完整对应中文文档（`README.zh-CN.md`、`docs/lunacode.zh-CN.md`、`services/lunacode-connect/README.zh-CN.md`），顶部支持一键互切，完整对比 LunaCode 与上游 T3 Code 差异并提供 Docker Hub 拉取、自打包、离线导出与反向代理部署步骤。

### 5. 授权审批、Git 历史与多账号合规加固（`LUNA-011` / `LUNA-013` / `LUNA-016` / `LUNA-018`）

- **授权审批单卡收敛**：待审批确认收敛为输入框顶部唯一确认卡，展开直接操作控件并中文化选项，避免与时间线卡片双卡重叠。
- **全仓库只读 Git 历史**：Web 与移动端新增全仓库只读提交历史分页浏览与提交详情查看入口。
- **多账号与 Antigravity 加固**：完善 Antigravity 合规配额读取与离线缓存恢复机制，并增强坏损/CgBI 媒体输入拦截与异常会话自动重建能力。
